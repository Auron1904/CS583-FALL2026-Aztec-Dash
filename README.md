## Current Target
Our current game idea is to create an endless 3D runner inspired by Temple Run. The player automatically moves forward through a continuously spawning path. The player switches between 3 lanes, where they must jump/slide to avoid both stationary and moving obstacles while an enemy chases them from behind. As the player progresses through the instance their run speed increases. The ultimate goal is to attain the highest distance score possible.
